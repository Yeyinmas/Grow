# 如何添加新关卡

本文档是「添加关卡」的速查手册：先看字符含义表，再按步骤新建 `.txt` 文件即可。

---

## 一、字符含义速查表

| 字符 | 含义 | 说明 |
|------|------|------|
| `.` | 可达地块 | 玩家和怪物都能走的地面 |
| `#` | 障碍物 | 谁都不能走的墙/石头 |
| `P` | 玩家出生点 | 每关有且只有一个 |
| `E` | 怪物出生点 | 可写多个，每个怪物都会追玩家 |
| `S` | 开关 | 玩家踩上后，打开本关所有门 |
| `G` | 门 | 初始关闭不可通行，踩过开关后打开 |
| `D` | 道具使用地 | 只有站在这里才能按 `1` / `2` 放道具 |
| `F` | 终点 | 玩家走到即胜利 |
| `V` | 藤蔓源 | 



---

## 二、添加步骤

1. 在 `Assets/Resources/Levels/` 下新建一个 `.txt` 文件，例如 `level4.txt`。

2. 按上面的字符含义填写地图：
   - 每行是地图的一行（从上到下）。
   - 所有行长度一致；某行短了，缺的部分会自动补成 `#`（障碍）。
   - 行与行之间直接换行即可，不要有多余的空格。

3. 用 `//` 写注释（可选），例如在文件开头写一句「第 4 关」。

4. 在 Unity 里新建场景，给 `Map Generator` 的 `Level File`（或 `Level Resource Name`）指向这个新文件，按 `md/Unity设置说明.md` 配置好即可运行。

---

## 三、示例：level3

`Assets/Resources/Levels/level3.txt` 内容：

```
###########
#P.###.G.F#
##D..#..###
#..#D...###
#..##.#.###
#E....#.S##
###########
```

这关的读法：

- `P`（左上）是玩家，`E`（左下）是怪物，`F`（右上）是终点。
- 终点 `F` 前面有一扇门 `G`，需要先踩到右下角的开关 `S` 才能打开门，再走到 `F` 获胜。
- 地图上有两个道具使用地 `D`，可以站在上面放置灌木丛或陷阱来阻挡/困住怪物。
- 本关没有藤蔓源（未写 `V` / `>` / `^` / `v`）。

---

## 四、检查清单

写完后对照一下，避免常见的坑：

- [ ] 有且只有一个 `P`。
- [ ] 至少有一个 `F`。
- [ ] 所有行等宽（或清楚知道短行会被自动补墙）。
- [ ] 门 `G` 对应的开关 `S` 玩家确实能走到。
- [ ] 从 `P` 到 `F` 存在一条可行路径（门开着之后能通）。
- [ ] 没有用 `#` 当作注释（注释要用 `//`）。
